# tiny-notes

간단한 메모 도구다. `notes.py` 로 메모를 츄가하고 목록을 본다.

## 사용법

    python notes.py add "장보기"
    python notes.py list

메모는 `notes.txt` 에 한 줄씩 쌓인다.

## 설정

설정 값은 `.env` 에 둔다. 이 파일은 저장소에 올리지 않는다.
